# CHAPITRE 19 : TACHEDUCATION & GENUC - L'INFRASTRUCTURE NUMERIQUE DE L'ENSEIGNEMENT SUPERIEUR AFRICAIN

## 19.0 Vision

Construire le plus grand ecosysteme numerique universitaire africain, capable d'accompagner chaque etudiant depuis son inscription jusqu'a sa carriere, en reliant dans une seule infrastructure l'admission, l'identite, la finance, les resultats academiques, les diplomes, la verification et la mobilite internationale.

Dans cette vision, GENUC devient le systeme d'exploitation universitaire. TachPay devient l'infrastructure de paiement, de preuve, de mobilite et d'interoperabilite qui prolonge l'universite au-dela de son campus. Ensemble, ils forment une plateforme continentale.

## 19.1 La Problematique Africaine

L'enseignement superieur africain fait face a des blocages recurrents :

- inscriptions lentes ;
- paiements difficiles ;
- manque de transparence financiere ;
- diplomes difficiles a verifier ;
- mobilite internationale compliquee ;
- gestion administrative manuelle ;
- absence de donnees consolidees.

Ces problemes ne sont pas isoles. Ils sont lies par une meme faiblesse : l'absence d'une infrastructure commune reliant le metier universitaire, la circulation de la valeur et la circulation de la preuve. GENUC + TachPay repondent a cette faille en unifiant les flux academiques, financiers et documentaires.

L'etudiant n'est plus un dossier disperse entre plusieurs bureaux. Il devient le centre d'un parcours numerique coherent et verifiable.

## 19.3 GENUC devient le Systeme d'Exploitation Universitaire

GENUC n'est plus seulement un logiciel de gestion. Il devient le systeme central de l'universite africaine.

Il porte la verite metier sur :

- les admissions ;
- les etudiants et inscriptions ;
- les promotions et annees academiques ;
- les cours, notes et deliberations ;
- les attestations, cartes etudiantes et diplomes ;
- les portails de service pour les roles universitaires.

C'est dans GENUC que naissent les evenements de reference : un dossier est valide, un matricule est cree, un frais devient exigible, une note est publiee, un jury cloture une deliberation, un diplome est emis. Cette position fait de GENUC le systeme source du chapitre 19.

## 19.4 Modules GENUC Connectes a TachPay

Le chapitre 19 prend toute sa force lorsque les modules GENUC sont relies directement aux capacites transverses de TachPay.

### Module Admissions

Le module admissions gere les demandes d'inscription, les candidatures internationales, les pieces justificatives, la validation des dossiers et l'emission des lettres utiles au parcours etudiant. TachPay y ajoute la couche de paiement, de preuve de transaction et de confirmation exploitable.

### Module Etudiant

Chaque etudiant dispose d'un TachStudent ID relie a :

- son identite verifiee ;
- son parcours academique ;
- ses paiements ;
- ses documents ;
- ses preuves partageables.

### Module Finance Universitaire

La connexion directe avec TachPay permet de gerer :

- frais academiques ;
- paiements ;
- recus ;
- dettes ;
- remboursements ;
- rapprochements et traces financieres.

### Module Comptabilite

Les ecritures, les rapprochements et les rapports peuvent etre automatises a partir d'une meme reference de paiement et d'un meme historique de confirmation. La finance universitaire cesse d'etre un angle mort entre caisse, banque et scolarite.

### Module Enseignant

GENUC conserve la gestion des cours, notes, evaluations et documents pedagogiques. TachPay n'a pas vocation a dupliquer ce coeur metier, mais a le prolonger lorsque les sorties de ce module doivent etre verifiees, partagees ou exploitees dans des services externes.

### Module Deliberation Intelligent

Le moteur de deliberation reste dans GENUC, avec ses calculs de moyennes, validations, jurys, bulletins et historiques. TachPay intervient lorsque les decisions doivent devenir des preuves portables, partageables ou monetisables dans de nouveaux usages.

### Module Diplomes Numeriques

GENUC produit le diplome comme verite academique. TachPay permet d'en faire un TachDiploma verifiable numeriquement, partageable, auditable et potentiellement connecte a des services de verification ou de mobilite.

## 19.5 TachStudent Passport

Le TachStudent Passport est l'innovation centrale du chapitre 19.

Chaque etudiant possede un passeport numerique academique pouvant contenir :

- diplomes ;
- attestations ;
- certificats ;
- competences ;
- paiements ;
- experiences ;
- preuves de verification.

L'etudiant controle le partage de ses informations. Il peut prouver un resultat, un paiement, une admission ou un diplome sans exposer l'ensemble de son dossier. Le TachStudent Passport transforme le parcours universitaire en actif numerique portable.

## 19.6 Paiement Etudiant International

Le paiement etudiant international constitue l'un des cas d'usage les plus puissants du systeme.

Avant TachPay :

- banque ;
- change ;
- transfert ;
- attente ;
- preuves difficiles.

Avec TachEducation :

- admission GENUC ;
- creation TachStudent ID ;
- paiement local dans la devise d'origine ;
- conversion automatique ;
- confirmation pour l'universite ;
- preuve numerique disponible.

Ce flux reduit la friction, augmente la confiance et rend enfin possible une mobilite regionale a grande echelle avec des preuves financieres fiables.

## 19.7 TachVisa Education

TachVisa Education organise la mobilite universitaire autour d'un dossier numerique coherent. Ce dossier peut reunir :

- admission ;
- paiement ;
- preuve financiere ;

L'objectif est de faciliter les demarches administratives aupres des organismes concernes selon les procedures applicables. TachVisa Education n'est pas un remplacement institutionnel. C'est une infrastructure de preparation documentaire et de confiance.

## 19.17 Architecture Technique

L'architecture cible du chapitre 19 repose sur une separation nette des responsabilites.

### GENUC Platform

GENUC reste le systeme source pour :

- admissions ;
- etudiants et inscriptions ;
- frais et obligations universitaires ;
- cours, notes et deliberations ;
- documents officiels et diplomes.

### TachPay Core

TachPay fournit les services transverses :

- paiement ;
- ledger ;
- webhook et confirmation ;
- verification et partage ;
- identite portable ;
- capacites transfrontalieres ;
- API partenaires.

### TachAI + TachData

TachAI et TachData ajoutent :

- analytics ;
- prevision ;
- scoring ;
- intelligence operationnelle ;
- lecture transverse du reseau universitaire.

### Les quatre premiers flux d'execution

La mise en oeuvre du chapitre 19 doit commencer par quatre parcours prioritaires :

1. admission validee dans GENUC -> creation TachStudent ID ;
2. frais academique GENUC -> paiement TachPay -> confirmation GENUC ;
3. deliberation ou diplome GENUC -> publication TachDiploma verifiable ;
4. etudiant GENUC -> TachStudent Passport partageable.

Cette approche permet de lancer un produit integre sans dupliquer le coeur universitaire dans TachPay.
